1. Introducción y métodos

La integración numérica aproxima una integral definida mediante valores de una función. Aquí se comparan el trapecio compuesto, Simpson 1/3 y Simpson 3/8; los datos del documento son didácticos, no mediciones reales de La Paz.

Trapecio compuesto

T = h[(f₀+fₙ)/2 + Σfᵢ]

Admite cualquier n positivo.

Simpson 1/3

S = h/3 [f₀+fₙ+4Σfᵢ impares+2Σfᵢ pares]

Requiere n par.

Simpson 3/8

S = 3h/8 [f₀+fₙ+3Σfᵢ no múltiplos de 3+2Σfᵢ múltiplos de 3]

Requiere n múltiplo de 3.

Espaciado: h = (b − a) / n. Error: |referencia − aproximación|; porcentaje = 100 × error / |referencia| (si referencia ≠ 0).

4. Informe técnico resumido

Objetivo: aproximar integrales de problemas de transporte, geometría, energía y otras áreas, verificando las condiciones de cada método.

Procedimiento: identificar magnitudes y unidades, definir el intervalo y los datos, calcular h, aplicar pesos de integración, comparar con una referencia cuando exista y analizar el error.

Interpretación: los resultados dependen del número de subintervalos y de la regularidad de los datos. Una aproximación no sustituye mediciones reales.

5. Pruebas de validación

Prueba obligatoria: integrar f(x)=x² desde 0 hasta 2; el valor exacto es 8/3 = 2.666666667.

También prueba manualmente valores no numéricos, longitudes distintas, x no creciente y n incompatible con Simpson.
